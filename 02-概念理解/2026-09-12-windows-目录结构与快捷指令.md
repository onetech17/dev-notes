# Windows 11 目录结构与快捷指令（程序员向）

- 日期：2026-09-12
- 标签：windows, 概念, 配置
- 关联笔记：[Linux AppImage 介绍](2026-09-02-Linux-AppImage介绍.md)、[Linux Electron 应用](2026-09-03-Linux-Electron应用.md)

## 一句话解释

`Program Files` 放程序本体、`AppData` 放你的数据（Roaming=配置、Local=缓存）、`ProgramData` 放全机器共享数据、注册表放系统设置；配合 `%变量%`、`shell:`、`.msc/.cpl` 三类快捷指令，可快速定位任何路径和管理面板。

## 核心机制：系统盘目录树

```text
C:\
├── Windows\                    操作系统本体（别动）
│   ├── System32\               系统级 DLL/EXE（64位系统里放的是64位文件，名字是历史包袱）
│   ├── SysWOW64\               32位兼容层（WOW64 = Windows 32-bit on Windows 64-bit）
│   ├── WinSxS\                 组件存储，系统更新的多版本备份（禁止手删，用 DISM 清理）
│   ├── Fonts\                  字体
│   ├── Temp\                   系统级临时目录
│   ├── Microsoft.NET\          .NET Framework 程序集
│   └── assembly\               旧版 GAC（全局程序集缓存）
│
├── Program Files\              64位程序安装目录
├── Program Files (x86)\        32位程序安装目录
├── ProgramData\               【隐藏】机器级、所有用户共享的程序数据（配置/许可证/更新包缓存）
│
├── Users\
│   └── <用户名>\               用户配置根目录（%USERPROFILE%）
│       ├── Desktop / Documents / Downloads / Pictures / Music / Videos
│       │                     「已知文件夹」，可右键→属性→位置整体迁移到 D 盘
│       ├── AppData\          【隐藏】当前用户的程序数据，核心中的核心
│       │   ├── Roaming\      漫游数据：配置文件为主，域账户换电脑会同步      → %APPDATA%
│       │   ├── Local\        本机数据：缓存、索引、大文件，不漫游            → %LOCALAPPDATA%
│       │   └── LocalLow\     低权限数据：浏览器保护模式、Unity 等沙箱程序
│       ├── .ssh / .gitconfig / .npmrc …   各 CLI 工具的配置（类 Unix 习惯）
│       └── ntuser.dat        注册表 HKEY_CURRENT_USER 的实体文件（别删）
│
├── $Recycle.Bin\             回收站（每个盘各有一份）
├── System Volume Information\ 系统还原点、索引服务数据（无权限，正常）
├── Recovery\                 恢复环境
├── pagefile.sys              虚拟内存交换文件
├── hiberfil.sys              休眠文件（powercfg /h off 可释放）
└── swapfile.sys              UWP/现代应用的交换文件
```

### 一个软件的四份数据

| 数据类型 | 位置 | 举例 |
|---|---|---|
| 程序本体 | `Program Files` / `Program Files (x86)` | exe、dll |
| 个人配置/缓存 | `AppData\Roaming`、`AppData\Local` | VS Code、JetBrains、微信 |
| 全机器共享数据 | `ProgramData` | Docker 镜像、服务端配置、授权文件 |
| 系统级设置 | 注册表（`regedit`） | 开机启动、文件关联 |

卸载残留通常在 **AppData 和 ProgramData**；排查"配置到底读哪个文件"也优先翻这三处。

## 关键细节：两个反直觉点

1. `System32` 在 64 位系统里放的是 **64 位**文件，32 位的反而在 `SysWOW64`；32 位程序访问 `System32` 会被自动重定向。
2. `ProgramData` 默认隐藏，但是 MySQL、Docker、Jenkins 等服务端软件存数据的地方，排查权限问题时常被忽略。

## 快捷指令（Win+R 或资源管理器地址栏直接输入）

### 1. `%变量%` —— 环境变量路径

| 指令 | 实际路径 / 用途 |
|---|---|
| `%appdata%` | `C:\Users\u\AppData\Roaming` —— 软件配置 |
| `%localappdata%` | `C:\Users\u\AppData\Local` —— 软件缓存/大文件 |
| `%programdata%` | `C:\ProgramData` —— 机器级共享数据 |
| `%userprofile%` | `C:\Users\u` —— 用户根目录 |
| `%temp%` / `%tmp%` | 用户临时目录（空间不够先清这里） |
| `%systemroot%`（=`%windir%`） | `C:\Windows` |
| `%systemdrive%` | `C:`（可写 `%systemdrive%\Users`） |
| `%programfiles%` / `%programfiles(x86)%` | 两个程序安装目录 |
| `%commonprogramfiles%` | `Program Files\Common Files` |
| `%public%` | `C:\Users\Public` 公共用户目录 |
| `%username%` / `%computername%` / `%os%` | 脚本中引用 |
| `%pathext%` | 可执行后缀列表 `.COM;.EXE;.BAT;.CMD;…` |

组合示例：`%appdata%\Code\User`（VS Code 配置）、`%userprofile%\.ssh`。

### 2. `shell:` 命令 —— 无固定物理路径的特殊位置

| 指令 | 打开位置 |
|---|---|
| `shell:startup` | **当前用户开机启动文件夹**（放快捷方式实现自启） |
| `shell:common startup` | 全机器开机启动文件夹（需管理员） |
| `shell:sendto` | 右键"发送到"菜单内容（可自定义） |
| `shell:appdata` / `shell:local appdata` | 两个 AppData |
| `shell:programs` / `shell:common programs` | 开始菜单程序目录 |
| `shell:desktop` / `shell:downloads` / `shell:mydocuments` | 各已知文件夹 |
| `shell:recyclebinfolder` | 回收站 |
| `shell:mycomputerfolder` | 此电脑 |
| `shell:controlpanelfolder` | 控制面板（Win11 藏得深） |
| `shell:administrative tools` | 管理工具 |
| `shell:fonts` | 字体安装目录 |
| `shell:connectionsfolder` | 网络连接 |

### 3. 系统管理命令（.msc / .cpl / 其他）

- 设备/服务/磁盘：`devmgmt.msc`（设备管理器）、`services.msc`、`diskmgmt.msc`、`compmgmt.msc`（计算机管理合集）、`eventvwr.msc`（事件查看器）、`taskschd.msc`（计划任务）、`certmgr.msc`（证书）、`gpedit.msc`（组策略，专业版以上）
- 控制面板项：`control appwiz.cpl`（程序和功能）、`ncpa.cpl`（网络适配器）、`inetetcpl.cpl`（Internet 选项/代理）、`sysdm.cpl`（系统属性）
- 其他：`regedit`、`msconfig`、`wf.msc`（防火墙）、`mstsc`（远程桌面）、`msinfo32`、`winver`、`cleanmgr`、`resmon`、`optionalfeatures`（启用 Hyper-V/WSL/沙箱）
- 直接打开环境变量编辑页：`rundll32 sysdm.cpl,EditEnvironmentVariables`

### 4. `ms-settings:` 协议（Win11 设置页直达）

`ms-settings:windowsupdate`、`ms-settings:defaultapps`、`ms-settings:network`、`ms-settings:storagesense`（存储感知）、`ms-settings:developers`（开发者模式）、`ms-settings:activation`。

### 5. PowerShell 对应写法

```powershell
$env:APPDATA              # 读变量（PowerShell 不支持 %xxx%）
$env:PATH -split ';'      # 查看 PATH
Get-ChildItem env:        # 列出全部环境变量（cmd 下用 set）
[Environment]::GetFolderPath('LocalApplicationData')   # 最权威的特殊目录 API
```

## 进阶补充

### 1. 环境变量管理

- 分「用户变量」（仅当前用户，免管理员）和「系统变量」（全机器）；装 JDK/Node 优先用户变量。
- `PATH` 从上到下顺序匹配，**同名命令前面的生效** —— 多版本 JDK/Python 切换失效基本都是这个原因。
- 用 `where.exe java`（非 PowerShell 的 where）查看命令实际解析到哪个 exe。

### 2. 开机启动项的四个藏身处

1. 任务管理器 → 启动应用
2. `shell:startup` 和 `shell:common startup` 文件夹
3. 注册表 `HKCU\...\Run`、`HKLM\...\Run`
4. `services.msc` 服务和 `taskschd.msc` 计划任务（最隐蔽）

### 3. C 盘空间治理

- Documents/Downloads 右键 → 属性 → 位置迁移到 D 盘；`%localappdata%` 下 Docker、pnpm、JetBrains 缓存是空间大户。
- 用目录联接把大目录搬到其他盘而软件无感知：先剪切数据，再 `mklink /J "原路径" "D:\新路径"`。
- WinSxS 只能用 DISM 清：`Dism.exe /online /Cleanup-Image /StartComponentCleanup /ResetBase`；日常开「存储感知」自动清 `%temp%`。
- 关休眠释放与内存等大的 hiberfil.sys：`powercfg /h off`。
- 全盘占用扫描推荐 **WizTree**（直接读 MFT，几秒出结果）。

### 4. 长路径与网络路径

- Win32 默认 260 字符路径上限，深层 node_modules 必踩：`gpedit.msc → 计算机配置 → 系统 → 启用 Win32 长路径`，或注册表 `LongPathsEnabled=1`。
- WSL 文件从资源管理器访问：`\\wsl.localhost\Ubuntu`（旧版 `\\wsl$\Ubuntu`）。
- 任意文件夹地址栏输入 `cmd` 或 `powershell` 回车，直接在该路径开终端。

### 5. 效率工具与排障

- **PowerToys**（微软官方免费）：PowerToys Run（Alt+Space 启动器）、FancyZones（窗口分区）、Hosts 编辑器。
- 查"文件被谁占用"：`resmon` → CPU → 关联的句柄 → 搜文件名，无需装软件。
- `powercfg /batteryreport`（电池报告）、`powercfg /sleepstudy`（睡眠唤醒分析）。

## 类比记忆

三层指令各管一摊：

- `%变量%` → 找**用户侧/系统路径**（数据在哪）
- `shell:` → 找**特殊文件夹**（UI 入口在哪）
- `.msc / .cpl` → 找**管理面板**（系统配置在哪改）
